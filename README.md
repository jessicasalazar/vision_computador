# Computer Vision — Course Repository

Minimal README for the **vision_computador** course repo. It lists the assignments and how to organize your work.

## Assignments

1. **HOG Feature Extraction**  
   Extract Histogram of Oriented Gradients (HOG) features and train a classic classifier (e.g., SVM or Logistic Regression).

2. **Pre-trained Models — Train the Classification Head** *(AutoGluon recommended)*  
   Use backbones like **ResNet-50** or **MobileNet**. Freeze the backbone and train a new classification head.

3. **Text–Image Retrieval (Image Retrieval)**  
   Build a system that retrieves relevant images from text queries (and/or text from images). CLIP/OpenCLIP embeddings are a good baseline.

4. **Pretext Task (Self-Supervised)**  
   Design a simple pretext task (e.g., rotation prediction, jigsaw, colorization) and show that features transfer.

5. **Airplanes Detection**  
   Train an object detector to find airplanes (YOLO/Ultralytics or Detectron2 are fine). Report mAP.

6. **SAM Segmentation**  
   Run **Segment Anything Model (SAM)** on sample images with point/box prompts and save mask results.
